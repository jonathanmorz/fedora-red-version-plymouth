---
## 🚀 Como Instalar

Siga os passos abaixo para instalar e ativar o tema na sua distribuição Linux (testado no Fedora).

### 1. Copiar a pasta do tema
Abra o terminal na raiz do repositório clonado e copie a pasta `themes` (ou o diretório específico do seu tema) para o diretório do Plymouth no sistema:

```bash
sudo cp -r themes/ /usr/share/plymouth/themes/fedora-red
